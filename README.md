
# 3CS Solutions – Homepage Redesign

A modern, futuristic homepage redesign for **3CS Solutions**, developed as part of the UI/UX Designer Practical.

## 🌐 Live Website

[View Live Website](https://3cs-homepage-eight.vercel.app/)

## 📌 Project Overview

This project is a redesigned homepage created to give 3CS Solutions a modern and engaging online presence. The design follows a futuristic technology-inspired theme, using dark backgrounds, glowing colours, interactive 3D elements and smooth animations.

The website presents the company's services, achievements, featured clients and contact information through a responsive and user-friendly interface.

## ✨ Key Features

- Modern futuristic UI design
- Interactive 3D hero section
- Smooth scrolling and reveal animations
- Responsive layouts for different screen sizes
- Services and company information sections
- Featured projects and client showcase
- Contact section with email interaction
- Consistent dark theme with cyan, blue and violet accents

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- Three.js
- React Three Fiber
- Framer Motion
- Lucide React

## 🚀 Running the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/shalinkauyanage/3cs-homepage.git
   ```

2. Open the project folder:

   ```bash
   cd 3cs-homepage/3cs-homepage
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 📦 Build

To create a production build, run:

```bash
npm run build
```
